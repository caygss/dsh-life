# 安全边界（模板文档）

1. **只绑本机**：示例里的服务全部监听 `127.0.0.1`，不要把管理口、模型端点、协议端暴露到公网。
2. **key 只走环境变量或宿主上的文件**：配置里写环境变量名（如 `apiKeyEnv`），不把 key 写进仓库、日志或消息。
   OneBot 的 token 例外地还支持 `config.tokenPath`：它指向**宿主上**的一个文件，插件只读该文件的字符串；
   这个文件放在仓库外、由宿主自己控制权限，插件不缓存也不回显。
3. **插件代码没有沙箱**：`create` 以宿主权限运行；安装第三方插件等于信任它的作者。
4. **协议端不是玩具**：OneBot 背后是真实账号，发出去的消息不可撤回地属于那个账号。
5. **模型输出是不可信输入**：工具参数来自模型，执行前该校验的还要校验（插件内部已有基础校验，但不替你做业务判断）。
6. **示例不是生产**：`examples/minimal-host` 没有持久化、没有重试、没有权限层，只用于跑通闭环。
